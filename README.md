# Скрипты сбора и анализа данных земельных участков (Томская область)

Автоматизированный инструмент для парсинга, предобработки и сбора характеристик земельных участков с площадок объявлений (включая Циан). Проект извлекает сведения о ценах, локациях, категориях земель, видах разрешённого использования (ВРИ) и наличии коммуникаций.

---

## Основной функционал

- **Парсинг объявлений**: обход страниц выдачи и карточек участков с настраиваемой глубиной парсинга (`max_pages`) и задержками между запросами.
- **Извлечение ключевых характеристик**:
  - Цена и удельная стоимость (за сотку/объект).
  - Геолокация: район, населённый пункт, точный адрес.
  - Категория земель и ВРИ (вид разрешённого использования).
  - Коммуникации (газ, электричество, водопровод/скважина) и инфраструктура (наличие построек/домика/бани).
- **Актуализация данных**: проверка и обновление дат публикаций и статусов объявлений.
- **Подготовка к выгрузке**: сбор структурированных данных для последующего анализа и сохранения в базу данных.

## Технологический стек
- Python 3.12
- Парсинг: BeautifulSoup4, requests
- Обработка данных: регулярные выражения (re), модуль datetime

## Быстрый старт
1. Клонирование репозитория:
git clone [https://github.com/val1tovvvv/script_for_analyzing_land_plots.git](https://github.com/val1tovvvv/script_for_analyzing_land_plots.git)
cd script_for_analyzing_land_plots
2. # Создание venv
python -m venv .venv

# Активация окружения (Windows PowerShell / CMD)
.venv\Scripts\activate

# Активация окружения (Linux / macOS)
source .venv/bin/activate

3. Установка зависимостей
pip install beautifulsoup4 requests
# Либо, если создан requirements.txt:
# pip install -r requirements.txt

4. Запуск скрипта
python script.py

---

## Нвстройки и параметры
В функциях сбора данных (например, worker_cian) вы можете скорректировать:
- max_pages — максимальное количество страниц для обхода.
- time.sleep() — интервал между сетевыми запросами для снижения риска блокировок.
- Списки ключевых слов (keywords) для поиска коммуникаций (газ, свет, вода).
